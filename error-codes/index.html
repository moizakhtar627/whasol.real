CODE 02
DC Bus Voltage Exceeded Overvoltage Threshold (>500V DC) Critical Trip
Growatt / Inverex • SPF 3000-5000 Series • Bus Sensor: Active
BUS_VOLT > 500.0V LIMIT: 450V NOMINAL
electric_bolt
SAFETY CRITICAL: Live High-Voltage DC Present

DC voltage remains stored across internal electrolytic bus capacitors even after AC breaker isolation. Wear class 00 1000V rated insulated gloves and wait 5 minutes before interior terminal contact.

biotech Root Cause Diagnostics
  • • Sub-Zero Open Circuit Voltage (Voc) Surge: PV array Voc rating exceeded max limit due to solar panel temperature coefficient during freezing weather conditions.
  • • DC Bus Capacitor Drift: Internal DC surge capacitors degraded or shorted by harmonic voltage spikes.
  • • Sampling Circuit Mismatch: Feedback resistor network misreading bus reference voltage.
build_circle Step-by-Step Field Solution
  1. Isolate the solar DC isolator switch immediately to protect internal MOSFET stages.
  2. Measure open circuit voltage across PV+ and PV- using a True-RMS calibrated digital multimeter.
  3. If measured DC voltage > 450V, split string series arrays into parallel configurations or remove 1-2 modules.
  4. Verify cold temperature multiplier: Voc(max) = Voc * [1 + (Tmin - 25) * Temp_Coeff].
  5. Discharge DC bus, re-engage DC switch, and perform controlled cold reboot.

CODE 08 / E08
Inverter Output Soft Start Failed (Inverter L-N Voltage Collapse) Critical Shutdown
Inverex / Voltronic Axpert • VM / King / Max Series • Stage: Inversion Sync
V_OUT < 180VAC TIME_WINDOW: 120ms
biotech Root Cause Diagnostics
  • • Massive Inductive Load Inrush: Motor compressor (e.g. 1.5-ton AC or submersible borehole pump) connected during initial boot cycle drawing >5x locked rotor amps.
  • • Output MOSFET Punch-Through: Short circuit failure in the H-bridge power module preventing AC sine wave synthesis.
build_circle Field Remediation
  1. Trip down the AC Output main circuit breaker physically.
  2. Power down the inverter fully via the power toggle rocker switch.
  3. Reboot system under zero-load condition and observe if error 08 clears to 230V nominal.
  4. Re-engage distribution breakers sequentially one-by-one to pinpoint the rogue heavy motor appliance.
  5. Install a dedicated motor soft-starter module on heavy inductive equipment.
DIAGNOSTIC STATUS: HARDWARE_PROTECTION_LOCK

CODE F103
Grid Overfrequency / Frequency Exceeded Islanding Threshold Grid Interruption
Sungrow SG / SH Series • Grid-Tied Commercial & Residential • Sensor: AC Phase Lock Loop
FREQ: > 50.50 Hz GRID_SYNC: HALTED
biotech Underlying Causes
  • • Utility Feed Unbalance: Local grid distribution substation shedding massive industrial loads, creating transient frequency spiking above 50.50Hz / 60.50Hz.
  • • Diesel Generator Frequency Jitter: Microgrid generator governor cycling wildly or hunting throttle positions.
  • • Country Grid Code Parameter Incompatibility: Incorrect regional compliance settings applied during initial inverter commissioning.
build_circle Calibration Steps
  1. Sample real-time utility frequency with a high-bandwidth digital power analyzer.
  2. Access the iSolarCloud mobile app via local Wi-Fi dongle connection.
  3. Verify country/region grid standard (e.g. VDE-AR-N 4105, EN 50549, or AS4777).
  4. If operating with on-site backup generator, calibrate generator engine mechanical governor to stable 50Hz (±0.2Hz).
  5. Inverter will automatically synchronize and ramp power within 300 seconds of grid frequency normalization.
ANTI-ISLANDING: IEEE 1547 COMPLIANT

CODE 56
Battery Communication Fault (BMS-Comm Failure / CAN Timeout) Warning (Derated)
Solis Hybrid S6 / RHI • Lithium Storage High/Low Voltage • Port: CAN / RS485
PACK_HEARTBEAT: TIMEOUT BATTERY STANDBY MODE
biotech Root Cause Diagnostics
  • • RJ45 Pinout Mismatch: Incompatible pin mapping between Solis CAN port (Pin 4: CAN-H, Pin 5: CAN-L) and third-party battery (e.g., Pylontech, Dyness, BYD).
  • • DIP Switch Addressing Error: Master battery module address set incorrectly, preventing master heartbeat beacon generation.
  • • BMS Protocol Selection: Inverter battery profile configuration mismatch in advanced setup settings.
build_circle Actionable Solution
  1. Verify communication cable crimp sequence using a standard RJ45 cable tester.
  2. Plug cable into dedicated CAN port on the Solis inverter, NOT into the DRM/Meter port.
  3. Set battery pack DIP switch #1 to UP (ON) and #2, #3, #4 to DOWN (OFF) for master unit designation.
  4. Navigate to Solis screen: Advanced Settings > Battery Select > Lead-Acid / Lithium > Select BMS Model.
  5. Restart the battery system first, wait for BMS contactor click, then power up inverter.
COMMUNICATION BUS: CAN 2.0B / 500kbps

CODE 2064
DC Arc Fault Detected (AFCI Hardware Safety Lockout) Safety Lockout
Huawei FusionSolar SUN2000 • Utility & Commercial String Units • Sensor: DSP Arc Fourier Analyzer
ARC_ENERGY > 120mJ CIRCUIT INTERRUPTED <2.5s
local_fire_department
FIRE HAZARD WARNING: Do NOT Blindly Clear Arc Alarms

Clearing AFCI 2064 via software without physical array inspection can reignite electric arcing across loose DC joints on combustible rooftop materials.

biotech Root Cause Diagnostics
  • • Corroded or Mismatched MC4 Connector: Water ingress into solar connectors leading to microscopic series arc flashing under high current draw.
  • • Cracked PV Module Junction Box: Burned bypass diode or fractured ribbon solder joint inside backsheet enclosure.
  • • Pinched Conduit Conductor: Mechanical insulation shear against aluminum mounting racking.
build_circle Remediation Protocol
  1. Isolate DC isolators and lock-out/tag-out the inverter cabinet.
  2. Conduct a thermal imaging camera drone sweep across the string to locate hotspot connectors.
  3. Inspect all MC4 joints along the flagged DC string for heat discoloration or charring.
  4. Cut and re-crimp verified genuine Stäubli MC4 connectors using specialized ratchet crimping tools.
  5. In FusionSolar App, connect locally as installer > Maintenance > AFCI Self-Check > Clear Alarm.

CODE F13
Grid Phase Sequence Reverse or Missing Neutral Connection Startup Hold
Deye SUN Hybrid Series • 3-Phase 8kW – 50kW Low/High Voltage • Detector: Phase Angle Sync
PHASE: CW MISMATCH RELAY LOCK: ACTIVE
biotech Root Cause Diagnostics
  • • AC Phase Rotation Counter-Clockwise: AC grid input conductors wired backwards (L1 & L2 swapped at the main AC breaker).
  • • Floating Neutral: Neutral wire loose or disconnected at the main distribution board or backup load port.
  • • High Neutral-to-Earth Potential: Earth ground fault causing N-to-PE potential to float >15V AC.
build_circle Field Verification
  1. Use a handheld handheld phase sequence rotation tester on the AC terminal block (L1, L2, L3).
  2. If tester indicates reverse rotation, switch off grid breaker and swap conductors L1 and L2.
  3. Measure voltage between Neutral (N) and Ground (PE). Nominal target: < 5V AC.
  4. Torque all AC terminal screws to manufacturer specification (typically 2.5 N·m).
  5. Restart inverter; Deye system will automatically verify 120° phase separation and engage contactor.
AC TOPOLOGY: 3L + N + PE / 400V
